# أطلِقها — دليل بناء SaaS

دليل عربي تفاعلي وخفيف لبناء وإطلاق منتج SaaS من الصفر. صُمّم ليعمل دون أي خطوة بناء أو اعتماديات: افتح `index.html` مباشرة، أو انشره عبر GitHub Pages.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة في المتصفح. ولتشغيل خادم محلي:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## النشر عبر GitHub Pages

1. ارفع ملفات هذا المستودع إلى GitHub.
2. من إعدادات المستودع، افتح **Pages**.
3. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`.
4. احفظ الإعدادات؛ سيظهر رابط الموقع في صفحة Pages خلال دقائق.

## الخصائص

- واجهة RTL عربية، متجاوبة للهاتف والكمبيوتر.
- سبع محطات عملية، مع خطوات قابلة للتنفيذ بدل النصائح العامة.
- حفظ تلقائي للتقدم وقوائم التحقق داخل متصفح الزائر فقط.
- بلا أطر عمل أو تبعيات — سريع جدًا ومناسب لـ GitHub Pages.

# أطلِقها — دليل بناء SaaS

دليل عربي تفاعلي وخفيف لبناء وإطلاق منتج SaaS من الصفر. يعمل دون أي خطوة بناء: افتح ملف HTML مباشرة، أو انشره عبر GitHub Pages.

يحتوي المستودع على نسختين مستقلتين من الدليل:

| النسخة | المسار | الطابع |
|---|---|---|
| **٢٫٠ — الحالية** | [`v2/`](v2/) | تدرجات حيوية وبطاقات زجاجية، بحث فوري، ٢١ أداة، وضع داكن |
| **١٫٠ — الأولى** | [`index.html`](index.html) | تايبوغرافي هادئ بأسلوب ثمانية، أداة واحدة لكل مرحلة |

النسختان تحفظان تقدّمهما بشكل منفصل، فالتقدّم في إحداهما لا يؤثر على الأخرى.

## النسخة ٢٫٠

- **سبع مراحل** من الفكرة إلى أول مستخدم، لكل مرحلة لونها الخاص يميّزها بصريًا قبل قراءة النص.
- **٢١ أداة مختارة** — ثلاث بدائل لكل مرحلة، مع سطر «متى تختارها» وشارة تكلفة ورابط رسمي.
- **بحث فوري** (`⌘K` أو `Ctrl+K`) يغطي المراحل والأدوات معًا، مع تطبيع للنص العربي حتى تعمل الكتابة بلا تشكيل.
- **جدول الستاك الكامل** مع فلترة بالمرحلة وبالتكلفة.
- **مفتاح «مسار سريع / تفصيلي»** يخفي الشروح ويُبقي الإجراءات والأدوات لمن يريد التنفيذ مباشرة.
- **نصوص جاهزة للنسخ**: رسالة طلب مقابلة، قالب العرض، ونص دعوة الإطلاق.
- **وضع داكن** يتبع النظام مع إمكانية التبديل اليدوي، و**حفظ تلقائي للتقدّم** داخل متصفح الزائر وحده.
- واجهة RTL متجاوبة، دعم كامل للوحة المفاتيح، واحترام إعداد «تقليل الحركة».
- خط **ثمانية**: `Thmanyah Serif Display` للعناوين و`Thmanyah Sans` للنصوص والأرقام وواجهة الاستخدام.

## التشغيل محليًا

يمكن فتح الملفات مباشرة في المتصفح. ولتشغيل خادم محلي:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173/v2/` للنسخة ٢٫٠، أو `http://localhost:4173/` للنسخة الأولى.

## النشر عبر GitHub Pages

1. ارفع ملفات هذا المستودع إلى GitHub.
2. من إعدادات المستودع، افتح **Pages**.
3. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`.
4. احفظ الإعدادات؛ سيظهر رابط الموقع في صفحة Pages خلال دقائق.

بعد النشر يصبح الرابطان:

- النسخة ٢٫٠ — `https://<user>.github.io/saas-launch-guide/v2/`
- النسخة الأولى — `https://<user>.github.io/saas-launch-guide/`

> ملف `.nojekyll` موجود في جذر المستودع حتى تُنشر المجلدات كما هي دون معالجة Jekyll.

## البنية

```
index.html · styles.css · script.js   النسخة الأولى
v2/index.html · v2/styles.css · v2/app.js   النسخة ٢٫٠
```

بلا إطار عمل، وبلا عملية بناء، وبلا اعتماديات npm — ملفات ثابتة فقط.

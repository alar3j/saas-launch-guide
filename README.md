# أطلِقها — دليل بناء SaaS

دليل عربي تفاعلي وخفيف لبناء وإطلاق منتج SaaS من الصفر. صُمّم ليعمل دون أي خطوة بناء: افتح `index.html` مباشرة، أو انشره عبر GitHub Pages.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة في المتصفح. ولتشغيل خادم محلي:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## النشر عبر GitHub Pages

1. ارفع ملفات هذا المستودع إلى GitHub.
2. من إعدادات المستودع، افتح **Pages**.
3. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`.
4. احفظ الإعدادات؛ سيظهر رابط الموقع في صفحة Pages خلال دقائق.

## الخصائص

- واجهة RTL عربية متجاوبة، مصممة للقراءة المريحة على الهاتف والكمبيوتر.
- خط **ثمانية الرقمي** للنصوص و**ثمانية للعناوين** للهرمية البصرية.
- سبع مراحل عملية بنمط موحّد: الفكرة، الفخ الشائع، الإجراء، ثم الأداة.
- حفظ تلقائي للتقدم وقوائم التحقق داخل متصفح الزائر فقط.
- تنقّل واضح، مؤشر تقدّم، دعم لوحة المفاتيح، واحترام إعداد تقليل الحركة.
- بلا إطار عمل أو عملية بناء — سريع ومناسب لـ GitHub Pages.
